📘 PrepMentor AI – AI Powered Mock Interview Platform

An AI-driven platform that helps students and job seekers practice interviews anytime, improve their communication skills, and receive instant AI-generated feedback.

🚀 Overview

PrepMentor AI is an AI-powered mock interview platform designed to bridge the gap between students and real interview environments. Many candidates fear interviews because they lack real-time practice, structured feedback, and exposure to domain-specific questions. PrepMentor AI solves this problem by acting as a virtual AI interviewer, offering personalized questions, evaluating answers, and providing detailed performance insights anytime, anywhere.
🎯 Key Features

✅ AI-Generated Interview Questions
Generates role-specific technical and behavioral interview questions using advanced AI models.

✅ Real-Time Mock Interview Simulation
Simulates a real interview by presenting one question at a time, creating a realistic experience.

✅ Instant AI Feedback
Evaluates user responses and provides suggestions on clarity, accuracy, and communication style.

✅ Progress Tracking Dashboard
Stores past interview sessions, feedback, and user improvement history.

✅ Modern, Responsive UI
Clean, fast, and user-friendly interface built using React and TailwindCSS.

✅ Secure Authentication
Uses Clerk authentication for secure and seamless user login and session management.

✅ Firebase Database Storage
All interview data, responses, and feedback are securely stored using Firebase Firestore.
